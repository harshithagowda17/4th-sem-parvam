# HotelBook Grand

A complete mock hotel booking website built with Next.js, React, and Tailwind CSS.

## Features

- User registration, login, profile, and booking history
- Hotel listings with images, ratings, full addresses, and offer badges
- Hotel detail pages with room/package selection
- Package inclusions such as food, pool, spa, shuttle, lounge, and guided tours
- Adult and children counters with dynamic price calculation
- Guest information and mock payment flow
- Booking confirmation and cancellation policy modal
- Admin dashboard with booking, revenue, and hotel statistics
- Admin hotel management for adding hotels, editing offers, and package prices
- Admin booking master list

## Data

The app uses realistic mock data and persists user actions in browser `localStorage`, so it runs without a database.

## Run

```bash
npm.cmd install
npm.cmd run dev -- --hostname 127.0.0.1 --port 3001
```

Open:

```text
http://127.0.0.1:3001
```
